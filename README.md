# ココヲコウ

画像・PDF・動画に矩形のコメントをつけ、位置・動画の時刻・コメントをJSONでAIへ渡すブラウザツール。

表示名は「ココヲコウ」。リポジトリ名・技術上のパッケージ名・サイトURLは`comment-to-picture`を維持しています。コメントJSONの保存ファイル名は`ココヲコウ-YYYY-MM-DD.json`です。

サイトURL: https://hirazisora.github.io/comment-to-picture/

## 動画対応

今後の開発は`dev`ブランチで行います。動画のローカル読込・再生／一時停止・シーク・縦スライダーによる音量調節に対応。範囲指定を始めると一時停止し、その`currentTime`を秒単位でコメントに保存します。コメント一覧の時刻を選ぶとその位置へ戻ります。未保存コメントがある状態で再生やシークを行うと確認を表示します。

MP4（M4V含む）／WebM。ブラウザの対応コーデックに依存し、この環境では自作H.264 MP4とVP8 WebMを検証しました。ファイル容量・合計容量・項目数・動画時間のアプリ独自上限はありません。画像・動画の寸法は4000万画素までです。再生時間・解像度を取得できない動画は非対応です。サーバー送信、変換サービス、追加ライブラリを使わず、[HTMLMediaElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement)とローカルBlob URLだけで処理します。

動画の`files`には`type: video`、`mime_type`、`duration_seconds`、`pages`の対応項目には`media_type: video`と`duration_seconds`、各コメントには`time_seconds`を追加します。原寸は表示フレームのピクセル寸法、範囲はフレーム全体の左上を基準に0〜1で表します。時刻は動画開始からの秒で、フレーム番号・時間範囲ではありません。動画バイナリやフレーム画像はJSONに含めません。`schema_version`と`exported_at`は復活させていません。動画を含まないJSONはmain版と同じ構造・内容です。

動画の枠は一時停止中、現在時刻の±0.1秒以内のコメントだけ表示します。ページ切替・削除・全削除で再生を停止し、srcを解除してBlob URLを解放します。音量は最初は0%（消音）です。再生ボタン左の縦スライダーで0〜100%を調節でき、上が最大・下が消音です。同じタブでのファイル切替後も選んだ音量を維持し、リロードで0%へ戻ります。

単体テストは`node --test tests/model.test.mjs tests/video-model.test.mjs`、ブラウザ検証は`node tests/video.mjs`（既存テストと同じ開発依存が必要）。自作動画・画像・PDFと通信記録は`test-results/`だけに生成します。

## 操作

画像はクリップボードからの貼り付け、画像・PDFファイルはドラッグ＆ドロップでも追加できます。コメント欄での通常テキスト貼り付けは維持します。URLのドロップでは外部取得しません。

画像・PDFを追加 → ドラッグで範囲指定 → コメント保存 → コメントJSONをコピー、またはコメントJSONを保存。画像上の枠・番号と右側一覧を同じ色で表示します。範囲の数値入力は不要で、ドラッグした正確な座標を保持します。入力途中のページ移動や出力では、保存・破棄・編集継続を選べます。同じファイルの再追加も独立した項目として受け付け、file_idで区別します。重複判定・全ファイルのハッシュ計算は行いません。

プレビュー内でホイールクリック（マウス中ボタン）を押しながらドラッグするとパンできます。左ドラッグは範囲指定です。パンは表示のスクロール位置だけを変更し、保存した範囲座標には影響しません。拡大した画像は表示枠内でスクロールします。中ボタンの解放、ホイール、ズーム、ページ切り替え、ウィンドウのフォーカス喪失・サイズ変更でパン状態を終了します。

クリップボードの書き込みが実際に成功した場合だけ、指定の成功メッセージをアプリ内ダイアログに表示します。閉じる／Enter／Escで閉じ、コピーボタンへフォーカスを戻します。コピー拒否時は成功表示を出さず、手動コピー用の代替画面を表示します。

元画像はJSONに含みません。AIへはJSONと元ファイルを別々に渡してください。座標は表示した画像／回転済PDF CropBoxの左上が(0,0)、右下が(1,1)。PDF原寸はポイント、画像原寸はピクセルです。全ページ（コメント0件も含む）を出力します。

一覧の×で画像・PDFのページを個別削除できます。「すべて削除」もコメント削除もアプリ内ダイアログで確認します。PDFを一部削除しても`page_number`は元PDFの番号を維持し、`page_count`は原本の総ページ数、`included_page_count`と`included_page_numbers`はJSONに残したページを示します。最後のページを削除したファイルはJSONから除外し、メモリ内の資産を解放します。原本のファイル自体は変更しません。

`instructions_for_ai`に、このJSONが別添原本への修正コメントであること、ファイル名・1始まりのページ番号による照合、export内の参照IDと外部取得IDの違い、原寸への座標変換、原本不足・対象不明時の確認を記載します。ツールの背景を共有していないAIにも、ユーザーが原本とJSONを手動で渡すだけで参照方法が伝わります。コメント原文は出力時に改変しません。

## プライバシーと制約

- ファイルとコメントはタブのメモリ内のみ。サーバー送信、解析、広告、外部フォント、外部CDNなし。サイト表示時にはGitHub Pagesから静的資産を取得します。
- CSPで外部通信・フォーム送信を制限。画像・動画はローカルBlob URLをブラウザへ渡し、アプリによるファイル全体のArrayBuffer読み込みを行いません。PDFのみ、解析・表示に必要なバイト列をキャンセル可能なFileReaderで読み込み、同梱のPDF.js worker・CMaps・標準フォント・WASMを使用します。PDF.jsの解析・描画にはPDFデータのメモリが必要です。
- リロード・タブ終了で作業は消えます。JSONを先に保存してください。JSONの再読込による作業復元は未対応です。
- 容量・項目数・動画時間による上限なし。画像・動画4000万画素、描画約800万画素。大容量・多数の入力は端末のメモリやブラウザの性能に依存します。PDFファイル読み取り・解析は各30秒、ページ情報10秒、画像15秒、動画読み込み30秒でタイムアウト。パスワード付きPDFは未対応。GIFは最初のフレーム。
- PNG、JPEG、WebP、GIF、BMP、PDF。現行のChrome・Edge・Firefox・Safari向け。クリップボード拒否時は手動コピー画面を表示します。
- 中止は読み込み中のファイルを破棄し、先に完了したファイルを維持します。取り除く操作は確認付き。

## 開発

依存インストール不要（PDF.js静的資産を同梱）。Node.js 22以上。

```sh
node --test tests/model.test.mjs tests/video-model.test.mjs
node scripts/build.mjs
node scripts/serve.mjs
```

http://127.0.0.1:4173 を開く。Pages workflowはテスト・ビルド後にdistのみデプロイ。ユーザー実ファイルや生成テスト成果物はコミットしません。

UIテストは開発用Playwright・pdf-lib・pngjsとPythonのpypdfが必要です。ローカルサーバー起動後、`node tests/save-regression.mjs`、`node tests/browser.mjs`、`node tests/deletion.mjs`、`node tests/pan-copy.mjs`、`node tests/import-inputs.mjs`、`node tests/video.mjs`、`node tests/no-import-limits.mjs`を実行します（`TEST_MODULES`でNodeパッケージのディレクトリ、`TEST_PYTHON`でPython実行ファイル、`TEST_URL`で確認対象を指定可能）。自作テストファイル・スクリーンショット・通信記録・全件チェックリスト・背景不要のJSON例はgit除外した`test-results/`に生成します。`TEST_BASELINE=1`の保存テストは旧版での不整合再現専用です。
